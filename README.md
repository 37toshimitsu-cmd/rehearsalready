# RehearsalReady landing page

Static English landing page connected to the published Tally form:
https://tally.so/r/Qo2y1X

## Publish

1. Extract `rehearsalready-lp.zip`.
2. Upload `index.html` to the root of a public GitHub repository.
3. In repository Settings > Pages, select Deploy from a branch, `main`, root (`/`).
4. Open the Pages URL and test the **Join early access** button.

For ongoing commercial SaaS hosting, check the hosting provider's terms; consider Cloudflare Pages or Netlify.

Before promoting broadly, confirm that the Tally form has no empty choices, submissions work, and any email collection has appropriate privacy/contact information.
